# Productlab Prompts

Free, ready-to-use Claude prompts for product leaders — built by the [Productlab](https://productlab.app) community.

Each prompt is a coaching session in a file. Paste it into Claude, answer the questions, get a real output.

---

## How to use any prompt

1. Open [claude.ai](https://claude.ai) (free account works)
2. Start a new conversation
3. Open the prompt file, copy everything after the divider line
4. Paste it into Claude and hit send
5. Answer the questions one at a time

Claude will guide you through the rest.

---

## Prompts

### [Executive Exposure Strategy Builder](./executive-exposure-strategy.md)

**The problem it solves:** You're doing great work but the right people don't know it. This prompt helps you build a personalised plan to become visible — consistently and authentically — to the executives who influence your career.

**Based on:** The Rule of 27 framework by Lucie McLean, product leader and executive coach at Productlab.

**What you get:**
- Your key audience mapped by relationship stage
- Your personal brand signal
- Specific touchpoints to show up in
- A 30/60/90 day action plan

**Time:** ~10–15 minutes
